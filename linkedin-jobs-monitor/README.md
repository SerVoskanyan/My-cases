# 🎯 LinkedIn Jobs Monitor: Автоматизация поиска вакансий

Интеллектуальная система для автоматического сбора и фильтрации вакансий из LinkedIn. Больше не нужно обновлять страницу поиска вручную — бот сам найдет релевантные позиции и аккуратно сложит их в таблицу.

## 🚀 Что делает этот проект?
- **Авто-скрапинг**: Собирает данные о вакансиях (заголовок, компания, локация, зарплата, описание).
- **Умная фильтрация**: Пропускает только те вакансии, которые содержат ключевые слова (например, "Digital", "Marketing").
- **Централизация**: Все результаты сохраняются в Google Sheets в режиме реального времени.

## 🛠 Технологический стек
- **n8n**: Ядро автоматизации (Workflow Engine).
- **Apify**: Обход защиты LinkedIn и извлечение данных.
- **Google Sheets API**: Хранение и структурирование данных.

## 📦 Как запустить у себя?
1. Импортируйте файл `Job_из_Linkedin_Sheets.json` в свой n8n.
2. **Настройте учетные данные:**
   - Замените `ВАШ_APIFY_API_TOKEN` в узле HTTP Request на ваш токен из Apify.
   - Подключите свой Google Account в узле Google Sheets.
3. Укажите `ID` вашей таблицы в настройках узла сохранения.
